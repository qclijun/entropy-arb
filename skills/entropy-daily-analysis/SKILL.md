# Entropy 每日价差分析

分析本项目 Entropy 与 Lighter、Lighter RH、trade.xyz 的分钟行情，输出中文报告及可复查证据。区分价差分布、条件性交易门槛、模拟收益与实际成交收益。

## 选择任务模式

- **日报／阈值统计**：执行数据检查与全量、近 48 小时、近 6 小时对比；只报告样本内候选参数。
- **套利机会／收益比较**：统计后增加策略回放。读取 [回放规则](references/replay.md)，统一比较条件后才能给出候选优先级。
- **报告分歧审计**：先取得双方原始输出、时间范围、参数和回放规则，再读取 [回放规则](references/replay.md) 做单因素比较。缺失证据保持 `UNKNOWN`。

所有模式均先读取 [数据与费用口径](references/data-and-fees.md)；生成报告前读取 [报告与证据要求](references/reporting.md)。

## 工作流程

1. **定位输入。** 从当前项目定位 `logs/`、`record/config-*.yaml`、`tools/analyze.py`；使用项目可用的 Python 环境，不依赖固定主机目录。按实际 CSV 与配置确认品种和对冲场所。
2. **固定样本。** 明确报告截止时间与时区，记录各文件哈希、有效分钟、重复／异常行、覆盖率和断档。比较时使用同一截止时间及可比较的窗口；处理过的数据另存，保留原始 CSV。
3. **确认费用。** 从对应配置和用户已提供的证据读取每腿费率，标注来源、核验时间及假设。无法验证的费率用具名情景分析，不能默认为零或写成已确认净利润。
4. **计算统计。** 使用 `tools/analyze.py` 对固定快照及近期窗口计算分布、候选阈值和触发分钟密度。历史窗口锚定报告截止时间；工具的 `--hours` 锚定运行时钟，离线复现时改用预先筛选的窗口副本。
5. **按模式验证。** 需要收益或排序时复用项目回放器，单列未平仓估值、断档持仓及费用敏感性。只做阈值统计时，不把分布更窄或门槛更厚写成收益更好。
6. **交付并停止。** 输出结论、每组关键数字、限制和证据路径；仅完成已请求的分析，保存本次交接说明。

## 关键约束

- 分钟内 `*_edge_max_bps` 只能用于触发统计；没有 tick 时间顺序和成交证据，不能当作可获取的成交价。
- 时间跨度与有效采样时长分开报告；触发分钟、成交批次、完整往返分开计数。
- 中枢漂移和近期窗口只用于识别状态变化，不把近期拟合参数称为“可交易参数”或样本外证明。
- 不在未来断档前最后一行虚构可执行的平仓；区间末清算只能列为估值。
- 不继承历史的固定推荐或排除名单。缺少可比证据时不给确定性收益排名。
- 本技能执行离线分析；不下单、不改交易配置、不重启采集器、不创建定时任务，也不自动写入用户记忆。额外操作以用户另行授权为准。
